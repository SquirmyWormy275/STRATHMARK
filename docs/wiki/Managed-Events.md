# Managed event workspace

The standalone `strathmark` command now accepts supplied data and operates a
persistent event through preparation, review, issue, outcomes, advancement,
correction and export. An optional shared graphical workspace uses those same
operations. Calculation-only clients remain independent.

The first managed profile uses the real V2 engine for synthetic individual SB/UH
rehearsals. It does not activate a live official workflow or replace existing V3
profiles. [Setup and commands](https://github.com/SquirmyWormy275/STRATHMARK/blob/main/docs/MANAGED_EVENTS.md)
describe installation, private storage, scoped browser sign-in, editor handover,
source results and fenced recovery.

Missoula is the integration testbed; a second synthetic show proves reuse.
MNEMEX remains optional during competition. See the
[cross-repository agreement](https://github.com/SquirmyWormy275/STRATHMARK/blob/main/docs/MODULAR_ECOSYSTEM.md).
