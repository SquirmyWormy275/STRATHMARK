# STRATHMARK ML Research Questions

Captures "would be nice to revisit" ML questions for future controlled
experiments. Add date and one-line description per question. Do NOT act on
these without specific findings driving the change.

This file is intentionally low-bar. If you encounter a question that you
suspect deserves an experiment but can't justify pulling on it right now,
write it here and move on. The list gets reviewed in retrospectives, not
sprint planning.
